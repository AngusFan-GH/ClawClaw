# MCP 连接

[English](mcp.md)

在「设置 → 集成 → MCP」中，本地命令选择 `stdio`，Streamable HTTP 选择 `HTTP`，旧版 HTTP+SSE 端点选择 `SSE`。SSE 使用桌面自有桥接进程，并通过现有上游客户端完成工具发现、调用、通知和有次数上限的重连，不修改固定版本的 Harness 子模块。桥接程序随桌面包构建，无需额外安装。

连接器名称也是工具命名空间，只能使用 1–32 位 ASCII 字母、数字、下划线或连字符，例如 `database_term`。远程 URL 必须使用 HTTPS；回环地址允许 HTTP。

使用 Bearer 令牌时，点击「添加请求头」，名称填写 `Authorization`，值填写 `Bearer 你的令牌`。值默认遮盖，ClawClaw 自动生成和管理凭据引用；设置仅保存引用，实际值写入凭据库。再次编辑时，已配置的值留空即可保留，输入新值即可替换，删除整行即可移除该请求头。替换值时会新建独立凭据，不影响复用旧凭据的其他连接。需要手动复用引用时，可选择「引用已有凭据（高级）」。HTTP 和 SSE 均可使用现有 OAuth PKCE 配置。

stdio 点击「添加环境变量」，填写 `API_KEY` 等变量名称及实际值。环境变量同样支持遮盖输入、自动凭据引用、保留或替换旧值及高级引用复用。环境变量名称区分大小写，请求头名称不区分大小写。切换传输方式时，环境变量与请求头分别保留草稿，仅保存当前传输方式对应的值。命令参数按行填写，输入框提供多行示例。

预注册 OAuth 客户端的密钥也可直接填写。已配置的密钥留空即可保留，填写新值即可替换；仍可通过高级选项复用已有凭据引用。

JSON 导入接受原始请求头值，并将其转存到凭据库：

```json
{
  "mcpServers": {
    "database_term": {
      "type": "sse",
      "url": "http://127.0.0.1:6061/sse",
      "headers": { "Authorization": "Bearer your-token" }
    }
  }
}
```

通过 `type` 或 `transport` 指定 `sse`、`stdio` 或 `streamable-http`（导入时也接受别名 `http`）。未显式指定类型时，有命令则使用 stdio，有 URL 则使用 Streamable HTTP。未知或冲突的类型会被拒绝。请选择服务器实际支持的传输方式；客户端不会根据 URL 路径推断 SSE，也不会自动回退到 SSE。
