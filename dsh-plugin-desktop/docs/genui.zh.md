# GenUI 结果卡片

[English](genui.md) | 中文

GenUI 提供默认关闭的结果卡片，支持图表、表格及隔离 HTML 的本地交互。它通过现有扩展点展示结果，不替换上游 Markdown 渲染器，不观察会话 DOM，不改变布局归属。固定的上游源码保持原样。

## 当前范围

产品目标是在聊天中直接展示有用的图表和小型交互片段。保留标准组件、隔离 HTML、重置／暂停／继续和文字回退；源码随会话保留。已有输入恢复作为便利能力，不承诺恢复任意自定义交互。自定义状态接口为兼容已有片段而保留，不作为默认生成要求。状态迁移、存储管理界面、分享协作、导出和更多组件暂缓，出现明确需求后再评估。

## 在测试 Profile 中启用

GenUI 默认关闭。在**设置 → 通用**中开启**可视化回答**即可。开关保存到当前 Profile，无需重启即可生效。与其他开关一致，点击后立即切换动画，保存时暂时禁用，不增加保存文字或改变行布局。保存失败时恢复已确认的值并显示错误提示；只读设置不可修改。实际渲染仍跟随 Host 已确认的状态。在同一位置关闭即可恢复文本结果。

如需手动配置，在当前 Profile 的 `cordis.patch.yml` 中新增或编辑以下覆盖项，放在插入条目之后：

```yaml
- id: desktop-genui
  config:
    enabled: true
```

手动编辑文件后重启 Host。现有设置传输也可以更新该条目的 `enabled` 字段。设为 `false` 后，模型工具、提示贡献和自定义结果视图一起移除；历史工具结果仍保留普通文本。Profile 准备过程保留明确设置，为旧 Profile 添加条目时不会自动开启。

可以直接要求模型展示可视化对比、计划或图表；开启功能后，提示会引导模型调用 `clawclaw_render_ui`，用户无需指定工具名称。小型可视化或 HTML 请求默认直接在聊天中渲染；提示明确要求不为展示或验证内联结果而先创建文件、启动服务、打开浏览器或执行浏览器自动化。明确要求网站、独立文件、导出或浏览器操作时仍按用户指定流程处理，必要的数据检索不受影响。`clawclaw_validate_ui` 只返回字段诊断，不展示卡片。`document` 参数示例：

```json
{
  "format": "clawclaw.genui/v1",
  "title": "服务状态",
  "items": [
    { "type": "stat", "label": "健康服务", "value": 3 },
    { "type": "table", "columns": ["服务", "请求数"], "rows": [["API", 20], ["Worker", 4]] },
    { "type": "progress", "label": "审查进度", "value": 50 }
  ]
}
```

工具参数优先使用 `document_json`：将完整文档序列化为一个 JSON 字符串，旧 `document` 对象参数继续兼容，二者只传一个。这样可避免部分模型调用将嵌套数组表达为 `{item: ...}` 包装对象。无效包装仍严格拒绝，不静默修复；校验失败会明确提示使用 JSON 字符串在对话内重试。

## 协议与归属

支持 `text`、`card`、`row`、`stat`、`table`、`progress`、`callout`、`steps`、`chart` 和 `html`。标准组件文本按字面呈现，隔离 HTML 预览以外不解释 HTML、任意样式、可执行表达式或模型动作。表格在本地排序，提供语义表头及排序状态。限制为序列化 JSON 64 KiB、200 个组件、8 层组件嵌套、表格 50 行及 12 列、24 个步骤、普通文本字段 2000 字符、标题或标签 160 字符。无效或超限文档返回诊断，不静默丢弃数据，也不自动修复。

Host 校验文档，通过工具输出协议生成可重放的 `meta`，同时保留可读文本结果。Client 再次校验元数据，只展示已经完成的结果；准备中或运行中的参数不会变成交互界面。每轮独立的成功结果按顺序显示在回答的公共尾部，位于折叠的工作详情之外。可选的 `resultId` 是最长 160 字符的非空白字符串，用于替换同轮同 ID 的结果，并保留原展示位置；省略 ID 则新增独立结果。失败或无效更新不能替换有效卡片，无法识别的元数据会单独保留文本回退。这里读取所属会话按轮划分的 Chat 投影，包括嵌套 PTC 结果与隐藏的过程节点；历史恢复无需再次调用模型。原始工具结果仍保留在工作详情中。元数据缺失、无效或版本未知时展示保存的文本。会话与调用身份来自所属视图。本地排序为临时状态，不写入共享存储，不发送模型消息。

功能跟随 Host 已确认的配置变化，清理工具、提示、Slot 和样式。结果源码保留在 Session 元数据中，另以有界的 Profile 存储域保存 HTML 展示状态，不将这些输入加入模型上下文。动作投递、业务草稿、导出、正文围栏和侧聊接入不属于当前产品范围。

## 图表与样式

图表使用 Apache ECharts 的 SVG 渲染。`chart` 节点支持 `kind`（`bar`、`line` 或 `pie`）、`title`、`categories`、`series`（每个序列包含唯一的 `name` 与 `values`）以及可选的 `unit`。例如：

```json
{ "type": "chart", "kind": "bar", "title": "服务请求量", "categories": ["API", "Worker", "Cache"], "series": [{ "name": "请求数", "values": [20, 4, 100] }], "unit": "次" }
```

每份文档最多 8 个图表，每图最多 60 个类别、4 个序列；饼图最多 12 个类别、1 个非负序列。数值必须有限且绝对值不超过 10^15。柱状图和折线图支持用 `null` 表示缺失值，零值仍按零处理。序列长度必须与类别数量一致。不接受任意 ECharts 配置、代码或 HTML。

点击图例只影响当前视图。饼图图例显示数值及当前可见类别的占比，筛选后明确说明统计范围，并提供“恢复全部”；数据表始终保留全部类别及占原始总和的比例。单序列柱状图和折线图显示序列名称，不提供多余的图例开关。每个图表都能展开语义数据表；空数据、全部隐藏、全部缺失或饼图总和为零时分别解释原因。隐藏的数据可一键恢复，渲染失败时自动展开数据表。图表跟随容器宽度及明暗主题变化；长名称或超过 8 个类别的柱状图改用横向条形图并支持纵向滚动，超过 12 个类别的趋势图支持横向滚动，保留全部数据与原始顺序。绘图区高度随内容调整，滚动视口限制高度。键盘用户可以滚动绘图区、展开精确数据表。卸载时销毁实例与观察器。卡片统一使用主题色、指标分组、轻量边框、数字列对齐及紧凑进度条。提示通过文字、图标与语义色区分提示、成功、警告及错误。模型提示要求给出简短结论，避免重复卡片数据；通用设置中提供具体的使用示例。

## 本地交互 HTML

纯 HTML 结果直接内联在聊天回答中，位于消息操作按钮之前，不显示外层结果卡片和重复文档标题，无需展开工具详情或打开其他页面；混合结构化结果仍保留卡片布局。

标准组件无法表达的小型计算器、筛选器或模拟器可使用 `html {type:"html",title:string,html:string,fallback:string}`。每份文档最多两个片段，每个片段的 UTF-8 源码最多 32 KiB；标题、源码及可读文字回退均为必填。工具文本保留文字回退，可执行源码仅随元数据保存，用于历史重放。

Client 在不透明来源的 `iframe` 中运行片段，只授予 `allow-scripts`。初始策略阻止外部资源、网络连接、嵌套框架、Worker、对象、基础 URL 和表单提交；支持内联 CSS 与 JavaScript，不支持外部库、导入和 eval。由于 CSP 本身不能阻止页面自行跳转，Electron 还会取消由 srcdoc 框架发起或以它为目标的导航；普通插件 iframe 的导航规则不变。不暴露 Electron、文件系统、会话、工具或特权操作接口。这是展示运行时，不是通用应用，也不对任意恶意工作负载提供完整隔离保证；尚无 CPU 与内存配额。

宿主只接受来源校验后的就绪、错误与有界高度消息（120–720 px），不接受操作命令；另以有界 JSON 消息只传输展示状态。主题切换通过消息更新片段，不重置本地输入。界面提供暂停／继续与折叠说明；“恢复初始值”作为次要操作放在说明内，明确清除保存的输入。加载与暂停保留内容区域高度，继续和重新加载沿用最近测得的高度。保存失败提供“重试”，不会重新加载片段；运行失败提供“重新加载”，保留当前输入。发生错误或启动超时八秒时显示文字说明。停止移除 iframe 但保留输入，可通过“继续运行”恢复；重置明确清除保存的输入，重新创建初始视图。读取或保存失败会明确提示，读取失败不会覆盖已有数据。原生输入、复选框、单选框、下拉框和文本域会自动保存在当前 Profile，刷新、重新打开历史或 Host 重启后恢复；密码、文件、隐藏、`data-private` 和 `autocomplete="off"` 字段不保存。恢复后触发 input/change 事件，使计算结果随之更新。自定义状态通过 `window.clawclaw.getState()` 和 `window.clawclaw.setState(json)` 读写；这不等于保存任意 JavaScript 内存，复杂交互需显式接入。每个片段最多保存 100 个控件及 16 KiB 有界 JSON，每个 Profile 最多 1000 份快照。达到上限明确报告保存失败，不静默淘汰已有数据。不要在片段中放入秘密信息，也不要模拟权限对话框；静态图表继续优先使用标准 chart 组件。

示例请求：“制作一个本地价格计算器，可输入单价和数量，实时计算总价，带重置按钮，并附文字说明。”用户无需指定工具名称。小型可视化或 HTML 请求默认直接在聊天中渲染；提示明确要求不为展示或验证内联结果而先创建文件、启动服务、打开浏览器或执行浏览器自动化。明确要求网站、独立文件、导出或浏览器操作时仍按用户指定流程处理，必要的数据检索不受影响。

架构借鉴隔离文档的一般方式，参考了本地可视化预览包装器及 [OpenAI 可视化概览](https://learn.chatgpt.com/docs/visualizations)。ClawClaw 运行时与样式为原创实现，不宣称复现 Codex 应用未公开的内部机制。

## 桌面实际验收

自动化及浏览器检查不能代替一次真实桌面验收。在运行实例中开启“可视化回答”，要求在聊天中展示价格计算器，检查内联交互、暂停／继续、刷新或切换会话后的恢复、明确重置及重新打开历史源码。图表检查图例筛选与原始数据表。优先修复实际遇到的问题，再考虑扩展能力。此清单在真实桌面实例中完成前保持待验收，不会自动启动图形应用。

## 验证与来源

运行 GenUI 专项测试、类型检查、构建及标准无界面检查。测试覆盖真实 DSH 工具注册表、Session 结果序列化与恢复、Profile 升级及开关，jsdom 中的组件渲染，以及无需浏览器或 GPU 的真实 ECharts SVG 渲染。这些测试不证明 Electron 实际绘制布局或真实模型行为；图形应用启动保持显式。
