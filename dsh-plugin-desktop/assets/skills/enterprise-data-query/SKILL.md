# 企业数据查询

这是一项查询工作流，不提供数据库驱动或 ERP/OA 接口。首先发现实际可用的连接器及工具，确认目标数据源、用户权限与查询范围。项目的 `database.sql` 能力映射和 PostgreSQL 目录项不代表当前已连接，也不代表其他数据库已完成适配。

## 数据源与口径

检查工具说明、数据库方言、允许的 schema/视图、字段字典及业务时间。用实际元数据确认字段、主键和关联基数，不从字段名猜测业务定义。默认获取完成任务所需的最少字段与聚合结果，沿用用户权限，不绕过行列限制。

ERP/OA 查询需明确具体系统、实例、实体、组织范围及接口的鉴权方式。优先使用已配置的只读接口或批准的报表视图。没有接口时，请求用户提供授权导出的 Excel/CSV；可以形成待执行 SQL 及字段需求，但不得声称查到了实时数据。凭据通过宿主的配置与密钥机制管理，不写进提示词、报告或技能资产。

## 执行查询

先限定日期、组织与返回规模，检查工具支持的超时、分页及聚合方式。只执行经确认无副作用的只读查询；不能仅凭语句以 SELECT/WITH 开头就推断安全，需排除写入 CTE、导出文件、锁、存储过程或有副作用的函数。只读权限由服务端账号、视图和连接器策略保证，提示词不能替代它们。

数据值使用连接器支持的参数绑定，标识符只来自已确认的元数据。先验证样本和总数，再做全量聚合；探查时的 LIMIT 不得污染最终总额。记录筛选条件、查询或调用参数、提取时间、分页状态和返回行数，敏感字段按权限最小化保留。

检查截断、分页未完成、超时、重复和关联后行数膨胀。发生权限错误时停止该数据源的查询并说明缺少的授权；查询失败时按错误修正，不能通过移除权限、组织或日期过滤来让查询通过。

## 交付边界

输出已验证的结果、口径、时间范围及完整性说明，后续统计交给 `data-analysis` 或 `business-data-analysis`。区分已执行结果、待执行查询和模拟示例。用户若要求修改业务数据，应作为单独写入任务处理，本技能不执行写入。
