# PDF 阅读与整理

先确定所需页范围、操作顺序、输出格式及是否要求保持版式。判断文本型、扫描型或混合型；抽取结果与页面对应，表格跨页时保留表头、单位和脚注，不能把空白抽取结果当作空白文档。

使用实际可用的本地 PDF 工具或已安装处理库。扫描页需 OCR 时先检查支持的语言及识别质量，金额、日期、姓名、负号和表格对齐应对照原图；识别失败的区域标明待核对。不为解决 OCR 依赖擅自上传文件。

合并拆分明确页码从一开始，保留原文件；检查旋转、尺寸、页序、书签与附件。转换到 Word/Excel 时区分文字提取与版面重建，说明扫描图、公式和合并单元格的可编辑性限制。

脱敏需真正移除底层文本、图像和相关元数据，再检查复制、搜索及文本提取结果。遮盖矩形或改字体颜色不等于删除信息；没有可靠脱敏工具时不声称已安全脱敏。

检查输出页数、页序和每页渲染；对数字或表格做抽样对账。数字签名、表单和权限可能随变更失效，应在有影响时告知。遇到加密文件要求合法密码，不绕过访问限制。

交付实际生成的文件、操作页范围、提取依据及需要人工复核的区域。
