# Data analysis

Begin with the decision the analysis must support. Define each metric's unit, population, numerator, denominator, time zone, date window, and comparison baseline.

Audit schema and field meaning, missing and duplicate values, malformed records, outliers, joins, filters, collection changes, sample size, and selection bias before interpreting results.

Keep raw facts, transformations, calculations, and interpretations distinguishable. Show formulas for important derived values and retain enough intermediate output to reproduce them. Use uncertainty ranges or scenarios when the input cannot justify a point estimate.

Choose charts according to the question. State axis units, aggregation, baseline, and notable exclusions. Avoid truncated scales and category overload when they could mislead.

Deliver the main finding, supporting calculations, data-quality caveats, plausible alternative explanations, and the next validation step. Correlation alone is not evidence of causation.
