# 企业经营数据分析

复用 `data-analysis` 的统计与数据质量原则。明确分析要支持的决策、数据来源、统计粒度、币种、单位、时间范围、时区和比较基准。区分订单额、收入、回款、成本与利润，不能自行替换口径。

## 获取和审计数据

读取本地 Excel/CSV 或已经取得的授权结果集。需要直连数据库、ERP 或 OA 时先使用 `enterprise-data-query`。表格操作可使用已有表格专家及 `tencent-local-office-edit`，先验证所需工具可用；不可编造工具执行结果。

多文件分析保留文件、工作表、行范围和提取时间的来源记录。检查表头、编码、日期、合并单元格、隐藏行、筛选、缺失与重复值。公式单元格的缓存值不能默认是最新计算结果；无法重算时标明影响。按文件大小选择分块处理或数据库聚合，不把预览样本当全量数据。

合并前确认业务主键、关联基数、币种和时间粒度。统计合并前后行数、未匹配行和金额，检测多对多连接导致的重复计数。清洗保留原始数据，记录丢弃或修正的规则，不自动将缺失值补零或删除异常值。

## 计算和解释

- 汇总：对数量、金额、订单数等先核对是否可加总；比例和均值从原始分子分母重算，不直接平均分组比例。
- 同比环比：按完整且可比的周期对齐。增长率为 `(本期 - 基期) / 基期`，基期为零时标记无法计算；负基期、缺失月份或未完结周期单独解释。跨币种需明确换算来源及日期。
- 经营指标：先确认收入确认方式、含税口径、退款与取消、成本归属和目标版本。毛利率为 `(收入 - 成本) / 收入`，完成率为 `实际 / 目标`；分母为零时不输出虚假百分比。
- 趋势：先按产品、地区、客户或产线拆分，检查季节性、工作日和数据口径变化。描述性变化、归因假设和预测分开；数据不足时给出缺口，不生成确定预测。
- 执行：使用可用的表格公式、SQL 或本地计算工具完成实算；保留查询、公式或分析脚本及关键中间表。计算环境缺失时只交付分析计划，不猜测数值。

## 报告与验证

报告包含主要发现、指标口径、数据截至时间、汇总与对比表、图表、异常解释、建议及数据限制。趋势图标明单位与时间轴，占比图注明总体；图和正文来自同一结果集。

交付前用独立汇总或抽样明细核对总额、分组小计和关键比例，检查筛选范围、行数截断与舍入差异。解释对账差额，不强行配平。交付实际生成的报告及可复算材料；不把图表建议称为已生成图表。

用户要求定期报告时，另行确认数据刷新时间、时区、调度服务、输出位置和失败处理。未配置并验证调度前，只能称为单次报告或可复用流程。
