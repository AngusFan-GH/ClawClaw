# PPT 汇报制作与改稿

先从上下文确定听众、汇报目的、时长、核心结论及品牌模板；有现成材料先读材料。将事实与建议区分，缺少数据的图表标注待补充，不编造业绩或引用。

按“结论、证据、下一步”组织叙事，每页只承担一个核心信息。先形成逐页标题、证据与讲述要点，再制作文件。长报告先筛选与听众决策有关的内容，不把段落逐页搬运。需要演讲稿时标明页码与时间分配。

可编辑 PPTX 使用实际可用的幻灯片工具；已安装的 `tencent-pptx` 区分新建、从材料生成、理解和改稿。修改本地文件时按所选工具读取 `tencent-local-office-edit` 等已安装技能。先确认运行依赖；工具不可用时可用已验证的本地 PPTX 库。只有 `ardot-slides` 画布或大纲时不能称为 PPTX 交付。

沿用模板的母版、主题、页面比例和页脚。尽量保留可编辑文本、表格与图表；需要截图时说明可编辑性边界。对用户指定的页面局部修改，避免无关页面变化。

逐页渲染核查文字溢出、图表单位、对齐、字号、图片裁切与备注；核对页数和所有数字。交付文件、讲稿及未解决依赖，说明未验证的字体或播放效果。没有实际文件时只交付明确标记的大纲。
