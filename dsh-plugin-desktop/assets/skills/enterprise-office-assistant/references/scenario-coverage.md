# 调查表场景覆盖与实施边界

本说明对应企业大模型算力平台建设需求调查表的日常办公、数据分析及第九节数据分析需求。能力判断基于项目资产与工作流；不代表客户环境已经验收。

| 调查项 | 项目能力与路径 | 实施条件 |
| --- | --- | --- |
| AI智能助手 | 企业办公助理编排问答、事项与文稿 | 发消息、日历及业务动作需要连接器和相应授权 |
| 文档撰写及修改润色 | 办公技能与现有写作、文档制作和本地 Office 技能 | 文件编辑需验证工具、模板与版面；迁移提示词不等于运行依赖齐备 |
| 文档总结摘要 | 办公技能提供来源定位和事实复核 | 扫描件需 OCR，超长文档需分段处理并检查覆盖完整性 |
| 报告生成 | 办公或经营分析技能输出证据、结论与建议 | 数字来自真实计算；Word/PDF 等文件需相应工具验证 |
| PPT辅助 | 逐页大纲、讲稿及已有幻灯片制作能力 | 可编辑 PPTX 交付需验证工具及版式，画布不能替代文件 |
| 信息检索 | 已有 evidence-research 与连接器能力 | 企业内部资料需要授权和索引，外部检索需网络及可用工具 |
| Excel分析及表格统计 | 现有表格专家、data-analysis 与新增经营分析技能 | 本地表格工具或计算环境可用，公式缓存需检查 |
| 数据查询 | 新增 enterprise-data-query 及现有 database.sql 能力映射 | 已有 PostgreSQL 目录项；其他数据库需实际适配，不能由能力别名推断支持 |
| 数据总结及趋势分析 | 新增经营分析技能提供口径、同比环比和分组复核 | 需足够历史数据，异常与趋势不能直接解释为因果或确定预测 |
| 经营数据分析 | 企业经营分析师复用统计、查询与经营分析技能 | 需财务及业务口径、目标预算、授权的 ERP/OA 导出或接口 |
| 自动生成分析报告 | 基于输入数据完成统计、图表与报告 | 单次生成可编排；定时运行需调度、凭据、失败通知和客户环境验证 |

新增技能解决任务编排和分析规范，新增专家提供可选择的专业入口。它们不新增数据库驱动、ERP/OA API、OCR 引擎或企业统一权限系统。缺少接口时可先用经授权导出的文件开展分析，不能声称已直接接入业务系统。

调查表还提出约千人、私有化及全国产化要求。这些属于平台实施条件，不能通过补充技能解决。需另行验证模型服务地址与鉴权、国产操作系统和硬件兼容、离线依赖与无外传策略、租户及行列权限、审计、并发与峰值压测、备份和运维。桌面应用的场景能力不能作为算力服务器选型或千人并发承诺。

## 客户环境验收样例

1. 用一份包含正文、表格和例外条款的真实办公材料完成摘要、修订、报告和可编辑 PPTX，核查来源、事实及版面。
2. 用多份月度 Excel 完成合并、去重、金额对账、同比环比、图表和报告，检查缺失月份、零分母及公式缓存。
3. 用客户只读数据库视图验证查询、超时、行数限制和权限隔离；再验证 ERP/OA 字段映射及导出数据与源系统对账。
4. 在目标私有化环境验证无外传、依赖可用性和实际峰值负载。定时报告另测重复运行、数据延迟和失败恢复。
