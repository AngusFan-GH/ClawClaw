# 文档版本对比

明确旧版、新版及比较范围；文件名和修改时间不一定代表版本顺序。读取全文、表格及与任务有关的页眉页脚、批注和附件，扫描件先核对 OCR。

按稳定标题、段落和表格键对齐，区分新增、删除、改写、移动和纯格式变化。目录更新或段落移动不应被重复统计为内容删除和新增。区分正文变化与提取顺序或 OCR 引起的差异。

优先核对金额、数量、比例、日期、责任主体、范围、否定词和承诺强度；报告列出旧文、新文、两边位置及实质影响。无法对齐或缺少页面时保留不确定性，不能宣称覆盖全文。

需要 Word 修订记录时使用支持真实 tracked changes 的工具，保留双方原文件；着色对照表不等同于原文件修订记录。合同差异可复用 `legal-contract-expert` 或 `risk-compliance-review`，但文本差异本身不代表法律结论或审批结果。

交付差异摘要、逐项清单与待确认项；未变化内容按需省略，不自动接受修订或覆盖正式版本。
