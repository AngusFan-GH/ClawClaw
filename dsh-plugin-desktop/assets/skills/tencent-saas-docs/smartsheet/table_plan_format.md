# table_plan 格式规范（C 端）

> 本文档定义 `smartsheet.create_table_from_plan` 工具 `table_plan` 参数的文本格式。
> AI 调用该工具前，需按本规范根据用户业务场景生成 `table_plan` 文本。
> 适用 C 端（腾讯文档 docs.qq.com）。

## 生成原则

- 输出**纯文本**，不要包含 JSON 或代码块标记（``` 等）
- 严格按照业务场景规划结构，不能有多余表格
- 表格标题格式：`## 表格N：表格名称`（禁止加 (T1)、(T2) 等内部编号标记）
- 每个表格只含：字段列表、视图列表、记录数量（可选）三部分，不得有其他内容
- 每个表格 5-15 个字段
- 单多选列必须列出选项文本

## 一、字段类型

枚举值：`[1, 2, 3, 4, 5, 6, 8, 9, 14, 15, 16, 17, 22, 26, 28, 25, 23]`

| 编号 | 类型 | 说明 |
|---|---|---|
| 1 | TEXT | 文本 |
| 2 | NUMBER | 数字 |
| 3 | CHECKBOX | 复选框 |
| 4 | DATE_TIME | 日期时间 |
| 5 | IMAGE | 图片 |
| 6 | ATTACHMENT | 附件 |
| 8 | URL | 链接 |
| 9 | MULTIPLE_SELECT | 多选 |
| 14 | PROGRESS | 进度 |
| 15 | PHONE | 电话 |
| 16 | EMAIL | 邮箱 |
| 17 | SINGLE_SELECT | 单选 |
| 22 | LOCATION | 位置 |
| 26 | CURRENCY | 货币 |
| 28 | PERCENT | 百分比 |
| 25 | AUTO_NUMBER | 自动编号 |
| 23 | USER_C | 人员（C端） |

> 尽量用单多选列代替人员列，选项可以是"张三""李四"等。

### 字段定义格式

    {序号}. {字段名} | {类型编号}
    {序号}. {字段名} | 17 | 选项：{选项1}、{选项2}、{选项3}        # 单选/多选必须列出选项
    {序号}. {字段名} | 25 | 编号规则：{规则}                        # 自动编号见第四章


## 二、引用规则

使用序号引用实体（用于视图分组、筛选、排序配置）：

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 表格 | T{序号} | T1 | 按出现顺序编号 |
| 本表字段 | F{序号} | F3 | 当前表格内字段序号 |
| 本字段选项 | F{序号}.O{选项} | F4.O1 | 单/多选字段选项 |
| 视图 | V{序号} | V1, V2 | 当前表格内视图序号 |

## 三、视图配置

### 3.1 视图类型

| 类型 | 说明 | 必需配置 |
|-----|------|---------|
| 表格 | 标准表格展示 | - |
| 看板 | 卡片看板 | 分组(单选/多选/人员) |
| 画廊 | 图片画廊展示 | - |
| 甘特图 | 时间线视图 | 开始和结束日期字段 |
| 日历 | 日历展示 | 开始和结束日期字段 |
| 表单 | 收集信息 | - |
| 查询 | 外界查询信息 | 必须指定查询字段 |

### 3.2 视图配置规则

1. 每个表格必须至少有一个不含筛选的表格视图
2. 至少有一个表格有含分组的表格视图
3. 表格和甘特视图可配置分组
4. 除了表单视图和查询视图，其余视图可配置筛选和排序
5. 不要以自动编号列为排序依据

### 3.3 筛选条件

- 筛选值必须为具体值或选项引用（如 `F4.O1`），禁止使用"当前成员""当前用户"等动态用户条件
- 逻辑词：
  - 等于、不等于、为空、不为空（所有列类型）
  - 包含、不包含（1, 9, 17 号列）
  - 大于、小于、大于等于、小于等于（2, 14, 28）
  - 早于、晚于（4）

### 3.4 视图定义格式与示例

    {视图名} | {视图类型}
    {视图名} | 表格 | 分组：F{字段序号}
    {视图名} | 表格 | 筛选：F{字段} 等于 F{字段}.O{选项} | 排序：F{字段} 升序
    {视图名} | 看板 | 分组：F{字段序号}
    {视图名} | 甘特 | 开始：F{开始日期字段} | 结束：F{结束日期字段}
    {视图名} | 查询 | 查询字段：F{字段1},F{字段2}

## 四、自动编号列（AUTO_NUMBER, 类型 25）

### 4.1 格式

    {字段名} | 25 | 编号规则：{规则描述}

### 4.2 规则片段

- 自增数字：`{N:位数}`，如 `{N:4}` → 0001, 0002...
- 固定字符：`{C:文本}`，如 `{C:PRJ-}` → PRJ-
- 日期：`{D:格式}`，格式可选 `YYYYMMDD`、`YYYYMM`、`YYMM`、`MMDD`、`YYYY`、`MM`、`DD`

### 4.3 示例

    订单编号 | 25 | 编号规则：{C:ORD-}{D:YYYYMMDD}{C:-}{N:4}
    → ORD-20260319-0001

### 4.4 注意事项

- 规则中至少有一个自增数字片段
- 每个表格最多一个自动编号列
- 不要以自动编号列为排序依据

## 五、记录数量（可选）

如果用户明确指定了某个表格需要的示例记录数量，则在该表格的字段列表之前添加 `### 记录数量` 段落，格式为一个数字。
如果用户没有指定记录数量，则不要生成此段落。

示例（用户指定了 10 条记录）：

    ## 表格1：员工信息表

    ### 记录数量
    10

    ### 字段列表
    ...
