# 仪表盘组件规划格式

## 组件命名规范

**使用业务语言命名**，而非技术术语或序号：
- ✅ 推荐：`项目状态分布`、`月度销售额趋势`、`高优先级任务数`
- ❌ 避免：`饼图1`、`柱状图`、`组件A`

命名应准确反映组件展示的业务内容或指标含义。

## 组件类型
| 简写 | 含义 | 子类型/说明 |
|-----|------|------------|
| T1 | 图表 | COLUMN(柱状图) / STACKED_COLUMN(堆积柱) / LINE(折线) / PIE(饼图) / DONUT(环形) / AREA(面积) |
| T2 | 表格 | 展示明细数据，⚠️ 必须指定分组字段 |
| T3 | 数字卡 | 关键指标KPI |
| T4 | 文本 | 标题或说明文字 |

## 格式强制约束（严格执行）

**每个组件必须使用多行缩进格式**，第一行为组件头（`组件名称 | T类型 | 子类型`），后续每个属性**独占一行**，以 `   - ` 开头（3个空格 + 短横线 + 空格）。

**严禁使用单行格式**：

待入职员工数 | T3 | 数据源：tI07GZ | 数值轴：COUNT | 主题色：3

此格式会导致解析器无法识别数据源等属性，造成创建失败。

**必须使用多行缩进格式**：

待入职员工数 | T3
   - 数据源：tI07GZ
   - 数值轴：COUNT
   - 主题色：3

## 数值轴写法硬性规则

- `COUNT` 表示统计记录数，必须**单独写成 `COUNT`**，不允许携带字段 ID，也不允许使用竖线。
  - ✅ `数值轴：COUNT`
  - ❌ `数值轴：f8zSUZ | COUNT`
  - ❌ `数值轴：任务状态 | COUNT`
- 字段聚合只支持 `fieldId | SUM/AVG/MAX/MIN`，**不支持 `fieldId | COUNT`**。
- 如果要统计某个状态/视图下的记录数，应通过 `视图：viewId` 或合法筛选限定数据范围，再写 `数值轴：COUNT`。
- 如果要表达“完成率”，只有存在百分比/进度/数字字段时才能使用 `fieldId | AVG`；如果只是统计已完成记录数，应命名为“已完成任务数”，不要命名为“完成率”。

## 规划文本示例

### 示例一：图表组件
```
组件名称 | T1 | COLUMN
   - 数据源：tableId（必填）
   - 视图：viewId（有合适视图时写此行；无视图则省略此行，表示全表）
   - 分类轴：fieldId（必填）
   - 数值轴：COUNT（统计记录数，必须单独写 `COUNT`）或 fieldId | SUM/AVG/MAX/MIN（数字字段统计；严禁 fieldId | COUNT）
            ⚠️ 无拆分轴时可以多个（逗号分隔，如 field1|SUM, field2|AVG），有拆分轴时仅支持单个
   - 拆分轴：fieldId（可选，不需要则省略此行）
   - 筛选：fieldId 操作符 值（可选，仅在无视图行即全表时可写；有视图行时不写此行）
      操作符：`=` `!=` `>` `>=` `<` `<=`
      合法值类型：optionId（选项ID，o开头）/ true|false（布尔）/ 数字字面量
      ⚠️ **严禁使用日期字段或日期值作为筛选条件**（如 `fieldId >= 2024-05-01`），日期格式不受支持，会导致编译失败
   - 主题色：0-13（可选，可根据图表含义选择合适颜色）
      * 0: 使用字段自带颜色（仅饼图可设置）
      * 1-5: 多色系混合
        - 1: 彩虹混色系
        - 2: 深色调混合系
        - 3: 浅粉紫+蓝系
        - 4: 多色低饱和系
        - 5: 蓝绿黄浅系
      * 6-13: 单色系渐变
        - 6: 纯蓝渐变
        - 7: 蓝紫渐变
        - 8: 纯绿渐变
        - 9: 纯青渐变
        - 10: 橙粉渐变
        - 11: 黄白渐变
        - 12: 棕米渐变
        - 13: 黑白灰渐变
   - 横轴标题：分类轴的业务含义（如"项目状态"、"月份"）⚠️ 仅 COLUMN/STACKED_COLUMN/LINE/AREA 需要，PIE/DONUT 不写此行
   - 纵轴标题：数值轴的业务含义（如"销售额"、"任务数量"）⚠️ 仅 COLUMN/STACKED_COLUMN/LINE/AREA 需要，PIE/DONUT 不写此行
```

### 示例二：表格组件
```
组件名称 | T2
   - 数据源：tableId（必填）
   - 视图：viewId（有合适视图时写此行；无视图则省略此行，表示全表）
   - 分组字段：fieldId（⚠️ 必填）
   - 主题色：0-9（可选，0深蓝/1浅蓝/2绿/3红/4橙/5黄/6紫/7粉/8黑/9灰，可根据数据含义选择颜色，如红色表示风险、绿色表示完成）
   - 筛选：fieldId 操作符 值（可选，仅在无视图行即全表时可写）
      操作符：`=` `!=` `>` `>=` `<` `<=` `CONTAINS` `DOES_NOT_CONTAIN` `IS_EMPTY` `IS_NOT_EMPTY`
      合法值类型：optionId（选项ID，o开头）/ true|false（布尔）/ 数字字面量。IS_EMPTY/IS_NOT_EMPTY 无需写值
      ⚠️ **严禁使用日期字段或日期值作为筛选条件**
```

### 示例三：数字卡组件
```
组件名称 | T3
   - 数据源：tableId（必填）
   - 视图：viewId（有合适视图时写此行；无视图则省略此行，表示全表）
   - 数值轴：COUNT（统计记录数，必须单独写 `COUNT`）或 fieldId | SUM/AVG/MAX/MIN（数字字段统计；严禁 fieldId | COUNT）⚠️ 仅支持单个
   - 主题色：0-9（可选，0深蓝/1浅蓝/2绿/3红/4橙/5黄/6紫/7粉/8黑/9灰，可根据数据含义选择颜色，如红色表示风险、绿色表示完成）
   - 筛选：fieldId 操作符 值（可选，仅在无视图行即全表时可写）
      操作符：`=` `!=` `>` `>=` `<` `<=` `CONTAINS` `DOES_NOT_CONTAIN` `IS_EMPTY` `IS_NOT_EMPTY`
      合法值类型：optionId（选项ID，o开头）/ true|false（布尔）/ 数字字面量。IS_EMPTY/IS_NOT_EMPTY 无需写值
      ⚠️ **严禁使用日期字段或日期值作为筛选条件**
```

### 示例四：文本组件
```
组件名称 | T4
   - 内容：标题或说明文字
   - 背景色：颜色代码，如#1450B8
   - 字体颜色：颜色代码，如#FFFFFF（可选，不指定时自动根据背景色计算）
```

## 数据选择原则

- **数值轴/度量**：**仅限**数字、货币、百分比、进度字段，可用 SUM/AVG/MAX/MIN
- **分类轴**：单选、多选字段
- **时间轴**：日期时间字段
- **禁止**：人员字段不能作为任何轴
- **⚠️ 文本字段不能做数值统计**：如果表格没有数字类字段，数字卡只能用 COUNT 统计记录数
- **⚠️ COUNT 只能统计记录数**：必须写成 `COUNT`，不能写 `fieldId | COUNT`；需要限定范围时用视图/筛选控制记录集合
- **⚠️ 多数值轴规则**：
  - 图表**无拆分轴**时，可以指定多个数值轴（逗号分隔），用于对比多个指标
  - 图表**有拆分轴**时，仅支持单个数值轴
  - 数字卡仅支持单个数值轴
- **不要使用以日期为筛选条件的视图作为数据源**
- **⚠️ 严禁在筛选条件中使用日期字段或日期值**（如 `fieldId >= 2024-05-01`）。仪表盘编译器不支持日期类型筛选值，此类写法必然导致编译失败。如需按日期范围取数，应先创建带日期筛选的视图，然后在组件中通过「视图」行引用该视图
- **优先直接使用已有 viewId 作为数据范围**；只有确实需要直接基于整张表取数时，才省略"视图"这一行表示全表

## 规划文本展示约束

⚠️ **仪表盘规划文本严禁向用户展示**。规划内容（包括组件类型、T1/T2/T3 标记、数据源 ID、字段 ID、筛选条件、主题色编号等）只能作为 `create_dashboard_from_plan` 的参数传入，不得输出到 assistant 消息文本中。用户可见的仅应为简短过渡文案（如"正在创建仪表盘"），不应看到任何规划细节。

## 无法满足需求时的处理

当用户需求无法满足时（如缺少必要的表结构信息、字段类型不支持统计、无合适视图等），**不要继续规划**，而是输出以下格式：

```
## 无法满足您的需求

### 原因
简要说明无法满足的具体原因

### 建议
- 建议1：如何调整需求使其可实现
- 建议2：替代方案
```

**常见无法满足的场景**：
- 表结构信息缺失（无 tableId/fieldId/viewId）
- 需要的字段类型不在支持列表中
- 字段类型与统计需求不匹配（如文本字段做 SUM/AVG）
- 无数字类字段时要求创建数值统计组件
