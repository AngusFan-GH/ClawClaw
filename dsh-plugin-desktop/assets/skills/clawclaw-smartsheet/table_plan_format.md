# table_plan 格式规范

> 本文档定义 `wb_smartsheet.create_table_from_plan` 的 `table_plan` 参数的文本格式。
> 调用该工具前，按本规范根据用户业务场景生成 `table_plan` 文本。
> 规划文本**只作参数传入，严禁展示给用户**。

## 生成原则

- 输出**纯文本**，不要包含 JSON，也不要包含代码块标记（``` 等）
- **一次调用只建一张表**：`table_plan` 里必须**恰好一个**表格段落。要建多张表就多次调用，每张走完「建表 → 填记录 → 补公式/关联列」再建下一张
- 严格按业务场景规划结构，不要塞与需求无关的列
- 表格标题格式：`## 表格1：表格名称`（禁止加 `(T1)`、`(T2)` 等内部编号标记）
- 表格段落只含三部分：记录数量（可选）、字段列表、视图列表；不得有其他内容
- 一张表 5–15 个字段
- 单选 / 多选列**必须**列出选项文本

## 一、字段类型

写类型**名字**，不要写数字：

| 类型名 | 含义 |
|---|---|
| `text` | 文本 |
| `number` | 数字 |
| `checkbox` | 复选框 |
| `date` | 日期时间 |
| `image` | 图片 |
| `attachment` | 附件 |
| `user` | 人员 |
| `url` | 链接 |
| `single_select` | 单选 |
| `multi_select` | 多选 |
| `progress` | 进度 |
| `phone` | 电话 |
| `email` | 邮箱 |
| `currency` | 货币 |
| `percentage` | 百分比 |

### 硬约束

- ⛔ **`formula`（公式）、`link`（关联）、`lookup`（查找引用）不要写进 `table_plan`。** 引擎在建表那一刻不接受这三类列（表还没有记录，关联目标甚至可能就是它自己），它们必须在表建好、记录填完之后用 `wb_smartsheet.add_fields` 单独追加（见 [formula.md](./formula.md) 与 [link_and_lookup_fields.md](./link_and_lookup_fields.md)）。

  写进去了也不会让整次调用失败：`create_table_from_plan` 会**照常建表**，跳过这几列，并在回执里给出 `deferred_columns`（跳过的列）与 `deferred_note`（补建指引）。看到 `deferred_columns` 时的正确动作是**接着补建**，而不是重发建表——重发只会在文档里多出一张同名表。
- ⛔ **不能写只读 / 系统维护的类型**：`created_user`、`modified_user`、`created_time`、`modified_time`、`auto_number`、`title`、`location`、`barcode`。这些列由系统维护，不能主动创建。
- ✅ **至少要有一列能当主列**：`text`、`number`、`date`、`url`、`phone`、`email`、`currency`、`percentage`、`progress` 之一。一张只有复选框和附件的表会被拒绝。第一列通常就该是这类（如「项目名称」`text`）。
- 没有 `select` 这个类型名：单选写 `single_select`，多选写 `multi_select`。
- 尽量用单选 / 多选列代替 `user` 列，选项可以是「张三」「李四」。

### 字段定义格式

    {序号}. {字段名} | {类型名}
    {序号}. {字段名} | single_select | 选项：{选项1}、{选项2}、{选项3}
    {序号}. {字段名} | multi_select | 选项：{选项1}、{选项2}

## 二、引用规则

用序号引用实体，仅用于视图的分组 / 筛选 / 排序配置：

| 对象 | 格式 | 示例 | 说明 |
|---|---|---|---|
| 字段 | `F{序号}` | `F3` | 本表字段列表中的序号 |
| 字段选项 | `F{序号}.O{选项序号}` | `F2.O1` | 单选 / 多选字段的第 N 个选项 |
| 视图 | `V{序号}` | `V2` | 本表视图列表中的序号 |

> ⚠️ 这些编号**只在这段规划文本内部有效**。建表完成后它们立即失效，后续调用（写记录、建公式列、配视图、建仪表盘）必须使用响应里返回的真实 `sheet_id` / `field_id` / `view_id`。拿 `F1` 去写记录，整批被拒绝为「未知 field_id」。
>
> 一次调用只建一张表，因此规划文本里**不存在跨表引用**，也没有 `T{序号}` 这种表引用。

## 三、视图配置

新建的子表**自带一个含全部列的默认表格视图**。`视图列表` 里写的是在此之上要额外建的视图。

### 3.1 视图类型

| 类型 | 说明 | 必需配置 |
|---|---|---|
| 表格 | 标准表格展示 | — |
| 看板 | 卡片看板 | 分组（单选 / 多选 / 人员字段） |
| 画廊 | 图片画廊展示 | — |
| 甘特 | 时间线视图 | 开始与结束日期字段 |
| 日历 | 日历展示 | 开始与结束日期字段 |
| 表单 | 收集信息 | — |
| 查询 | 外界查询信息 | 必须指定查询字段 |

### 3.2 视图配置规则

1. 至少有一个**不含筛选**的表格视图（作为总览）
2. 表格视图与甘特视图可配置分组；建议至少有一个带分组的表格视图
3. 除表单视图与查询视图外，其余视图可配置筛选与排序
4. 画廊 / 日历视图不支持分组
5. 看板视图的分组字段必须是单选 / 多选 / 人员字段

### 3.3 筛选条件

- 筛选值必须是具体值或选项引用（如 `F2.O1`）。**禁止**「当前成员」「当前用户」这类动态用户条件
- 逻辑词按字段类型选用：

| 逻辑词 | 适用字段类型 |
|---|---|
| 等于、不等于、为空、不为空 | 所有类型 |
| 包含、不包含 | `text`、`single_select`、`multi_select` |
| 大于、小于、大于等于、小于等于 | `number`、`progress`、`percentage`、`currency` |
| 早于、晚于 | `date` |

### 3.4 视图定义格式

    {视图名} | {视图类型}
    {视图名} | 表格 | 分组：F{字段序号}
    {视图名} | 表格 | 筛选：F{字段} 等于 F{字段}.O{选项} | 排序：F{字段} 升序
    {视图名} | 看板 | 分组：F{字段序号}
    {视图名} | 甘特 | 开始：F{开始日期字段} | 结束：F{结束日期字段}
    {视图名} | 查询 | 查询字段：F{字段1},F{字段2}

## 四、记录数量（可选）

只有用户**明确指定**了示例记录条数时，才在字段列表之前加 `### 记录数量` 段落，内容是一个数字。用户没指定就**不要**生成这个段落。

    ## 表格1：员工信息表

    ### 记录数量
    10

    ### 字段列表
    ...

> 记录本身不由 `create_table_from_plan` 写入。建表返回后，用真实 `field_id` 调 `wb_smartsheet.add_records` 填数据。

## 五、完整输出示例

    ## 表格1：项目管理表

    ### 字段列表
    1. 项目名称 | text
    2. 项目状态 | single_select | 选项：规划中、进行中、已完成
    3. 项目负责人 | single_select | 选项：张三、李四、王五
    4. 开始日期 | date
    5. 结束日期 | date
    6. 项目预算 | currency
    7. 完成度 | progress
    8. 是否重点项目 | checkbox

    ### 视图列表
    1. 总览视图 | 表格
    2. 按状态分组 | 表格 | 分组：F2
    3. 未完成视图 | 表格 | 筛选：F2 不等于 F2.O3 | 排序：F5 升序
    4. 状态看板 | 看板 | 分组：F2
    5. 项目时间线 | 甘特 | 开始：F4 | 结束：F5
    6. 项目查询 | 查询 | 查询字段：F1,F2

> 这张表若还需要「预算执行率」（公式）或「关联任务」（关联列），**不要**写进上面的字段列表——建表成功、`add_records` 填完记录之后，再用 `wb_smartsheet.add_fields` 追加。

## 六、解析失败怎么办

服务端会指出**具体不合规的位置与原因**（哪一行、哪个字段、为什么）。按提示改文本后重试，不要原样重投。最常见的三类：

| 报错 | 原因 |
|---|---|
| 出现了不允许的字段类型 | 写了 `formula` / `link` / `lookup`，或写了只读类型，或写了 `select` |
| 没有可作主列的字段 | 全表都是复选框 / 附件 / 图片一类 |
| 单选 / 多选字段缺选项 | `single_select` / `multi_select` 后面没有 `选项：...` |
