# 办公文档翻译与本地化

明确源语言、目标语言、地区、读者和输出形式。沿用用户术语表、品牌名称和历史译法；专名、缩写或技术术语存在歧义时列候选，不无依据地统一成某个含义。

保持标题层级、段落、表格、脚注、引用及图片说明的对应关系。翻译数字、单位、日期和币种时不擅自换算；需要本地化日期或单位时保留原值及换算依据。公式、链接、产品代码和占位符按用途保留。

逐段翻译后对照原文核查遗漏、增译、否定关系、义务和不确定性，特别检查 must/may/should 等强度。营销或习语可按读者调整，但不能改变事实和承诺。扫描件识别不清的内容先标明，不猜测原文。

需要保持可编辑文件时，按文件类型复用 `office-word-workflow`、`office-ppt-workflow` 或 `office-excel-workflow` 并确认工具可用。翻译后的文本长度可能改变分页、图表和行高，交付前检查完整布局。

交付译文或双语文件、关键术语及待核对项。不能完成文件重建时明确只提供文本译稿，不声称保留了全部排版；不擅自上传原文到外部翻译服务。
