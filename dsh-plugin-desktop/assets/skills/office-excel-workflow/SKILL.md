# Excel 办公表格与公式

识别新建工作簿还是修改现有文件，确认字段、单位、日期格式、汇总口径与输入输出区。台账使用一行一条记录，稳定业务主键；标题区与数据区分开，避免在数据区域用合并单元格组织记录。

新建工作簿可复用已安装且可运行的 `tencent-docs-sheet-generation`；既有表格使用 `tencent-docs-sheetagent` 或所选通道对应技能，本地编辑器使用 `tencent-local-office-edit`。先确认可用工具与具体参数；无专有运行依赖时可使用可用的本地表格库，不假装调用成功。

保留原始明细，另设汇总或分析工作表。公式区分常量和输入，核查绝对/相对引用、跨表引用、单位与空值；分母为零需定义业务处理，不用错误捕获掩盖错误口径。日期、编号和长数字避免被自动转换或丢失前导零。

合并多表前对齐表头、数据类型和主键，记录重复、未匹配行及合并前后行数与金额。清洗先保留副本，不默默删除异常。CSV 导出会丢失公式、样式和多工作表，需说明影响；用户文本以字符串写入，防止被误作公式执行。

交付前重算公式并检查错误值、汇总与明细对账、数据验证、冻结窗格、筛选及打印范围。未能重算时说明公式缓存未验证。用图表表达趋势时核对源范围和轴单位。涉及经营指标和归因时转用 `business-data-analysis`。

交付可打开的 XLSX、使用方法及修改说明；不执行宏，不自动发布或发送文件。
