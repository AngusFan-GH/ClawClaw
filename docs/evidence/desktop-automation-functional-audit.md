# 自动化任务逐项功能核验报告

核验日期：2026-10-23（Asia/Shanghai）。产品版本：ClawClaw 0.2.11，DSH 0.2.1-rc.2。

状态：本报告所列自动化任务功能核验完成，发现的问题已修复，最终全量测试与完整门禁通过。

## 范围与方法

本报告覆盖此次升级、Schedule 迁移和页面调整涉及的**自动化任务模块**：列表、表单、详情、每个按钮、客户端导航、管理 API、官方调度接入、执行账本、持久化、会话及历史保留。完整仓库门禁同时覆盖其他模块的既有回归测试，但不代表对整个产品的所有第三方服务完成了人工端到端验收。

有副作用的按钮通过 jsdom 中的真实 React 组件事件、模拟 API，以及临时 Profile 中的官方 Schedule/离线模型进行核验；运行、取消、删除、故障注入和重启不会作用于用户的真实任务。生产窗口仅进行查看和会话导航。没有为本次核验点击真实任务的“立即运行”，没有发送测试消息。

测试用例执行真实组件的按钮、表单提交和输入事件，断言请求内容、可用状态和错误恢复；不以截图或源码文字匹配替代操作逻辑。菜单单元测试使用遵守 disabled 的 Menu 替身，另有不替换组件的真实 DSH Menu 集成测试，验证 portal、选项禁用、Escape、外部点击及分钟选择。完整 Profile 集成使用实际官方计时器、存储、会话和投递组件，离线模型代替外部付费模型。

## 发现并修复的问题

1. **打开旧会话误报未知**：rc.2 的列表只表示目录，`binding()` 只返回已被客户端引用的会话。改为官方 `sessions.using()`，为重命名操作保留临时引用，操作完成或失败均由官方服务释放，随后正常导航。
2. **手动运行无法停止**：运行 API 等待执行结束，原共享 busy 状态连停止按钮一起禁用。取消改用独立状态和互斥引用，允许在对应的运行请求未返回时停止；重复停止受保护。
3. **无效友好规则沿用旧表达式**：清空星期、无效间隔会触发转换失败，原代码保留了旧表达式。预览和保存现在都从当前友好表单重新计算，失败时禁止保存。
4. **保存抢在预览之前或采用过期预览**：按规则内容绑定预览结果，只有当前规则的成功预览才允许保存；忽略已经失效的异步结果和错误。
5. **单次执行时区不一致**：输入、预览、编辑回显和列表日期统一遵守所选 IANA 时区，不再默认按机器本地时区解释单次输入；未改变日期时间时保留已有瞬间的秒数。DST 缺失或重复的本地时刻明确拒绝，要求另选时间。
6. **旧读取结果覆盖操作后的状态**：通过读取序号丢弃较旧请求的返回，避免暂停后被先前的轮询响应重新显示为启用。
7. **快速重复点击**：除渲染层 busy 外增加同步互斥引用，防止同一渲染批次发出重复运行或保存请求。
8. **运行中按钮与服务端限制不一致**：任何任务正在执行时，禁用新建、编辑、启停、删除及另一次运行；查看和必要的停止操作仍可用。
9. **初次读取失败无重试入口**：空列表上的错误提示增加刷新按钮；保存失败保留输入，停止失败恢复停止按钮。
10. **保存过程中仍可改表单**：保存时禁用表单字段和返回按钮，失败后恢复字段；避免正在发送的内容与界面新输入不一致。
11. **归档说明与迁移策略不一致**：文案改为先取消归档再启用，归档任务的启用菜单不可点；不再承诺下一次自动创建新会话。
12. **跳过记录显示超长耗时**：跳过显示“未执行”，普通跳过原因不再用失败样式；原始记录不重写。
13. **旧记录的计划时点不能代表完成时间**：已完成等执行记录显示实际 finishedAt，只有跳过记录使用错过的计划时点；避免旧数据中 scheduledFor 偏向下一次计划导致展示日期错误。历史增加手动/定时来源，便于分辨主动重跑与调度发生。

## 调度与持久化核验矩阵

| 功能 | 核验结果 |
|---|---|
| 官方定时器 | 临时 Profile 的单次任务只触发一次、只调用一次离线模型，记录真实结果 |
| 单一调度所有者 | driver 模式禁止启动旧计时器；同 Profile 的进程租约拒绝竞争实例 |
| 不补跑 | 启动、睡眠错过、过期消息和旧核心目标均不会触发回放 |
| 避免重复执行 | 持久化认领先于执行；重复发生时点/消息、重叠任务被拒绝；写认领失败不调用执行器 |
| 执行结果 | 正常完成、异常、超时、取消、中断分别落账；会话 flush 后记录结果 |
| 管理隔离 | 自动化运行期间不能通过任务管理工具再次创建或运行调度 |
| 会话持续性 | 复用原会话和工作区；不通过新建会话掩盖缺失或归档问题 |
| 归档停止 | 取消在途执行、持久化停用；后续启用前必须取消会话归档 |
| 删除保留 | 移除调度项后仍保留会话和归档历史 |
| 重启 | 临时持久化 Profile 两次重启，任务、会话、历史及归档保持，旧消息不触发模型 |
| 首次与重复迁移 | 两个旧任务、40 条旧记录、原 ID 和会话关联均保留，不重复导入 |
