# ClawClaw macOS 安装说明

[English](install-macos.en.md) · [Windows 安装说明](install-windows.md)

## 下载前

ClawClaw 提供 Universal DMG，同一个安装包适用于 Apple 芯片和 Intel Mac。安装包已包含运行环境，无需安装 Node.js、pnpm 或开发工具。系统版本要求以所选版本的发布说明为准。

从项目提供的下载入口获取macOS 安装包（`.dmg`）。下载前查看系统要求，选择适合自己电脑的安装包。

## 安装

1. 双击下载的 `.dmg` 文件，等待磁盘映像打开。
2. 将 `ClawClaw.app` 拖到“应用程序”（Applications）文件夹，等待复制完成。若磁盘映像中没有文件夹快捷方式，可在访达中打开“应用程序”后复制进去。
3. 推出 ClawClaw 磁盘映像。
4. 在“应用程序”文件夹中打开 ClawClaw。后续也从这里启动，避免直接运行 DMG 内的副本。

复制到“应用程序”时，系统可能要求输入本机管理员凭据。

## 首次打开时被 macOS 拦截

如果安装包未签名或未公证，首次打开可能提示无法验证开发者或无法检查恶意软件。确认文件来自项目提供的下载入口且你信任该下载后，可按 [Apple 的说明](https://support.apple.com/102445)操作：

1. 先在“应用程序”中尝试打开 ClawClaw，然后关闭拦截提示。
2. 打开“系统设置 → 隐私与安全性”，向下找到 ClawClaw 的拦截记录。
3. 点击“仍要打开”（Open Anyway），按系统要求认证，并在后续提示中确认打开。

如果没有该按钮，或电脑受单位策略管理，请联系管理员。若提示文件已损坏或将损害电脑，先停止打开，重新从项目提供的下载入口下载并报告问题；不要把这类提示直接当作开发者验证提示处理。无需关闭整个系统的 Gatekeeper 或删除隔离属性。

## 完成首次配置

1. 按首次启动向导完成设置；可跳过允许跳过的选项，稍后在设置中调整。
2. 按界面提示连接模型；也可稍后进入“设置 → 模型”配置。所选模型可能需要 API 密钥和网络，安装应用不等于已获得模型服务凭据。
3. 打开默认工作区或添加自己的文件夹，创建会话并发送一条消息，确认模型能够回复。

关闭主窗口通常只会隐藏窗口，应用仍在后台运行。可从菜单栏托盘重新打开；需要完全停止时，选择托盘中的“退出”。

## 更新

更新前保存工作并备份重要数据。可使用应用的检查更新功能，或从项目提供的下载入口下载新版 DMG 后手动安装。

macOS 的应用内更新会下载并校验安装包，然后打开 DMG，仍需手动替换：从托盘退出 ClawClaw，将新版 `ClawClaw.app` 复制到原“应用程序”位置，确认替换，复制完成后再启动。不要在旧应用仍运行时覆盖它。

## 卸载与数据保留

从托盘退出 ClawClaw，再将“应用程序”中的 `ClawClaw.app` 移到废纸篓。删除应用不会删除以下本地数据：

| 内容 | 默认位置 |
| --- | --- |
| 配置、Profile、会话和插件状态 | `~/.clawclaw/data` |
| 默认工作区文件 | `~/.clawclaw/workspaces/default` |
| 应用状态、缓存和日志 | `~/Library/Application Support/ClawClaw` |

`~` 表示当前用户主目录。自定义数据目录和额外工作区可能在其他位置。需要彻底清理时，先核对实际路径并备份，再自行删除；重装也不会自动清空这些数据。

## 遇到问题

- 打不开 DMG：确认下载完整，重新下载 macOS 安装包。
- 复制提示应用正在使用：从托盘退出后再试，关闭窗口不等于退出。
- 应用能打开但无法对话：检查“设置 → 模型”中的密钥、模型配置和网络。
- 启动异常：可从托盘导出诊断；无法进入界面时，在终端执行已安装的程序：

  ```sh
  /Applications/ClawClaw.app/Contents/MacOS/ClawClaw --export-diagnostics
  ```

如果安装在其他位置，请调整命令路径。向项目维护者反馈时，请附上 macOS 版本、芯片类型、ClawClaw 版本和复现步骤，分享日志或诊断包前检查并移除敏感内容。
