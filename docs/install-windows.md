# ClawClaw Windows 安装说明

[English](install-windows.en.md) · [macOS 安装说明](install-macos.md)

## 下载前

当前 Windows 正式安装目标为 **x64**。可在“设置 → 系统 → 系统信息”查看系统类型；当前没有原生 Windows ARM64 或 32 位安装包。系统版本要求以所选版本的发布说明为准。

从项目提供的下载入口获取Windows x64 的 Setup 安装程序（`.exe`）。下载前查看系统要求，选择适合自己电脑的安装包。

## 使用安装程序

1. 双击下载的 ClawClaw Setup 安装程序（`.exe`）。
2. 根据安装向导阅读许可说明并继续。默认面向当前用户安装；如需更改安装位置，在向导中选择目录。
3. 点击安装并保持安装窗口打开。安装可能需要几分钟，请等待完成。
4. 安装完成后启动 ClawClaw；后续可从开始菜单或桌面快捷方式打开。

默认当前用户安装位置通常为 `%LOCALAPPDATA%\Programs\ClawClaw`；实际位置以安装向导中选择的目录为准。如果系统请求管理员权限，请先确认正在运行的是刚下载的 ClawClaw 安装程序。

## Windows 提示保护了你的电脑

如果安装包未进行代码签名，Windows 可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。微软说明，未签名文件可能出现信誉警告，单位策略也可能禁止继续。参见 [Microsoft SmartScreen 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

确认文件来自项目提供的下载入口且你信任该下载后，如果 SmartScreen 提供“更多信息 → 仍要运行”，可以选择继续。若没有继续选项，或被单位策略、Smart App Control 或杀毒软件阻止，请保留提示并联系管理员或项目维护者。无需关闭系统防护；明确的恶意软件告警应先排查。

## 完成首次配置

1. 按首次启动向导完成设置；可跳过允许跳过的选项，稍后在设置中调整。
2. 按界面提示连接模型；也可稍后进入“设置 → 模型”配置。所选模型可能需要 API 密钥和网络，安装应用不等于已获得模型服务凭据。
3. 打开默认工作区或添加自己的文件夹，创建会话并发送一条消息，确认模型能够回复。

关闭主窗口通常只会隐藏窗口，应用仍在后台运行。可从任务栏通知区域（含隐藏图标）重新打开；需要完全停止时，选择托盘中的“退出”。

## 更新

更新前保存工作并备份重要数据。可使用应用的检查更新功能，或从项目提供的下载入口下载新版 Setup 安装程序，退出 ClawClaw 后安装到原位置。应用内更新校验下载后，会先关闭 Host，再启动安装程序；如果提示应用仍在运行，请从托盘退出后重试。

## 卸载与数据保留

从托盘退出，在 Windows“设置 → 应用”中找到 ClawClaw 并卸载。

卸载保留本地数据、工作区、应用状态、缓存和日志：

| 内容 | 默认位置 |
| --- | --- |
| 配置、Profile、会话和插件状态 | `%USERPROFILE%\.clawclaw\data` |
| 默认工作区文件 | `%USERPROFILE%\.clawclaw\workspaces\default` |
| 应用状态、缓存和日志 | `%APPDATA%\ClawClaw` |

可将上述路径粘贴到文件资源管理器地址栏。自定义数据目录和额外工作区可能在其他位置。需要彻底清理时，先核对实际路径并备份，再自行删除；重装也不会自动清空这些数据。

## 遇到问题

- 安装耗时较长：保持窗口打开并等待完成，不要反复启动多个安装程序。
- 提示应用正在运行：检查通知区域，从 ClawClaw 托盘选择退出，再重试。
- 应用能打开但无法对话：检查“设置 → 模型”中的密钥、模型配置和网络。
- 启动异常：可从托盘导出诊断；无法进入界面时，在 PowerShell 执行已安装的程序：

  ```powershell
  & "$env:LOCALAPPDATA\Programs\ClawClaw\ClawClaw.exe" --export-diagnostics
  ```

如果更改了安装位置，请调整命令路径。向项目维护者反馈时，请附上 Windows 版本、系统类型、ClawClaw 版本、安装方式和复现步骤，分享日志或诊断包前检查并移除敏感内容。
